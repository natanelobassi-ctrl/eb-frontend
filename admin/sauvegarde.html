💾 Sauvegarde des données

Cette fonction permet de télécharger une copie des données enregistrées dans le navigateur : élèves, enseignants, classes, notes, paiements, absences, internat et autres informations du logiciel.

Conseil : effectuez régulièrement une sauvegarde, notamment avant une modification importante du système.

♻️ Restaurer une sauvegarde

Sélectionnez un fichier de sauvegarde .json précédemment téléchargé depuis ce logiciel.

Attention : la restauration remplace les données actuellement enregistrées dans ce navigateur.

⚠️ Zone de sécurité

Utilisez cette fonction uniquement si vous souhaitez effacer toutes les données enregistrées sur cet appareil.
